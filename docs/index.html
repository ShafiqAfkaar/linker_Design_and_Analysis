Design the connection.

A focused Python workflow for generating protein linker backbones, designing sequences, validating predicted structures, and measuring linker geometry and confidence.

Pipeline

From fixed motifs to ranked designs.

The orchestration script connects established protein-design tools in four stages and keeps their outputs in a consistent directory structure.

RFdiffusion

Generates candidate linker backbones between user-selected structural regions.

ProteinMPNN

Samples amino-acid sequences for candidate structures while retaining fixed positions.

ColabFold

Predicts each designed sequence for structure-based validation.

PDB analysis

Extracts linker measurements, labels candidates, and writes a ranked CSV report.

Measured outputs

A compact structural readout.

The standalone analyzer reads predicted PDB structures and summarizes the region between the fixed N- and C-terminal segments.

Sequence

Residue sequence assigned to the linker interval.

pLDDT

Mean local prediction confidence read from PDB B-factors.

Distance

Cα-to-Cα end-to-end distance across the linker.

SASA

Mean solvent-accessible surface area over linker residues.

Quick start

Analyze predicted PDBs.

The analysis component requires Python, NumPy, and Biopython. The complete design workflow additionally requires configured RFdiffusion, ProteinMPNN, and ColabFold installations.

Read the documentation

Prediction confidence is not equivalent to experimental stability. Computational candidates should be interpreted carefully and validated experimentally.

git clone https://github.com/ShafiqAfkaar/linker_Design_and_Analysis.git
cd linker_Design_and_Analysis
python -m pip install -r requirements.txt

python analyze_linker.py \
  --input /path/to/pdb_results \
  --phage_len 100 \
  --pep_len 20 \
  --output ./linker_results
